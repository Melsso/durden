WHAT IS DURDEN

Durden is a real-time object detection tool built around a YOLO model. Upload an image, and the model returns every object it recognizes — each with a label, a confidence score, and a bounding box — rendered directly on top of your image.

It's built for quickly sanity-checking a model's output: dragging in a photo, tuning the confidence threshold, and seeing exactly what the network is picking up and how sure it is.

HOW IT WORKS

  • You drop or select an image on the Detect page.
  • The browser sends it to the backend as a multipart/form-data upload.
  • A YOLO model runs inference and returns labels, confidence scores, and bounding box coordinates for everything it finds.
  • The frontend draws each box directly onto the image, color-coded by object class, and lists every detection in a sortable table below.
  • A confidence slider lets you filter out low-confidence detections without re-running inference.

STACK

The backend is a FastAPI service wrapping a YOLO model for inference, exposing a simple /predict endpoint plus a /status endpoint for health and model information.

The frontend is plain HTML, CSS, and JavaScript — no build step or framework — talking to the API directly with fetch and drawing detection boxes on an HTML canvas.

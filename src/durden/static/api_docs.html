API REFERENCE

This is a quick reference for the endpoints Durden exposes. For the full interactive spec — try-it-out requests, schemas, and every field — see the auto-generated Swagger UI or ReDoc.

POST /predict

Runs object detection on an uploaded image (JPEG, PNG or WEBP, up to 10 MB). Accepts a multipart/form-data body with the image file; the model and confidence threshold are optional query parameters. Returns 503 while models are still loading.

REQUEST

POST /predict?model_name=yolov8n.pt&conf=0.25 Content-Type: multipart/form-data file: <binary image data> model_name (query, optional) default: first configured model conf (query, optional) 0.0 - 1.0, default 0.25

EXAMPLE

curl -X POST "http://localhost:8000/predict?conf=0.25" \ -F "file=@city_street.jpg"

RESPONSE 200

{ "filename": "city_street.jpg", "model_name": "yolov8n.pt", "detections": [ { "label": "car", "confidence": 0.94, "bbox": [120, 280, 420, 520] }, { "label": "bus", "confidence": 0.90, "bbox": [520, 220, 780, 480] } ], "inference_time_ms": 132.4 }

bbox is [x1, y1, x2, y2] in pixel coordinates relative to the uploaded image's original resolution.

ERRORS

400 not a valid JPEG/PNG/WEBP image, or unknown model_name 413 file larger than 10 MB 422 invalid query parameter (e.g. conf outside 0 - 1) 503 models still loading or failed to load
GET /status

Returns version, environment, start time, the list of loaded models and whether they are ready. Used to populate the system status card and model selector on every page.

RESPONSE 200

{ "name": "Durden Object Detection API", "version": "0.1.0", "environment": "production", "started_at": "2026-07-09T08:12:43Z", "models": ["yolov8n.pt", "yolov8s.pt", "yolov8m.pt"], "model_state": true, "model_error": null }
GET /health

Liveness check. Always returns 200 while the process is up. status is loading, ok or error depending on model loading.

{ "status": "ok", "models_ready": true }
GET /ready

Readiness check. Returns 200 once all models are loaded and 503 until then, which makes it suitable as a container startup or readiness probe.

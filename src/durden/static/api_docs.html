API REFERENCE

This is a quick reference for the two endpoints the frontend uses. For the full interactive spec — try-it-out requests, schemas, and every field — see the auto-generated Swagger UI or ReDoc.

POST /predict

Runs object detection on an uploaded image. Accepts a multipart/form-data body with the image file, and optionally a specific model name to run inference with.

REQUEST

POST /predict Content-Type: multipart/form-data file: <binary image data> model: "yolov8n" (optional)

RESPONSE 200

{ "filename": "city_street.jpg", "detections": [ { "label": "car", "confidence": 0.94, "bbox": [120, 280, 420, 520] }, { "label": "bus", "confidence": 0.90, "bbox": [520, 220, 780, 480] } ], "inference_time_ms": 132.4 }

bbox is [x1, y1, x2, y2] in pixel coordinates relative to the uploaded image's original resolution.

GET /status

Returns service health, version, and the list of available models. Used to populate the system status card and model selector on every page.

RESPONSE 200

{ "name": "Durden Object Detection API", "version": "0.1.0", "environment": "development", "started_at": "2026-07-09T08:12:43Z", "models": ["yolov8n", "yolov8s"] }
